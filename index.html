AI (Gemini)
Add your own free Gemini key so the AI works right inside Ideary. How to get one (2 minutes):
  1. Open aistudio.google.com/apikey and sign in with any Google account.
  2. Tap Create API key (if it asks, pick "Create in new project").
  3. Copy the long key that appears (it starts with AIza).
  4. Paste it below. It's free; Google only limits how many requests per minute.
If you're connected to Google Drive, it's saved in your own Drive so you don't have to enter it again on other devices. Otherwise it stays only in this browser.
